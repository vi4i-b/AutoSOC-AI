# AutoSOC — полное руководство пользователя

Это пошаговая инструкция по всему приложению: от входа до расследования
инцидента, подключения серверов и реагирования.

---

## 1. Первый запуск

1. Установите зависимости и запустите приложение (см. [README](README.md)).
   - Linux: `sudo -E .venv/bin/python main.py` (sudo нужен для управления
     firewall, чтения `/var/log/auth.log` и изоляции эндпоинтов).
   - Windows: запустите от имени администратора.
2. Откроется окно входа.

## 2. Вход и регистрация

Есть два способа войти:

- **Учётная запись ОС** — введите тот же логин и пароль, что при входе в
  компьютер (Windows — через LogonUser, Linux — через PAM). Отдельная
  регистрация не нужна.
- **Локальная учётка AutoSOC** — нажмите **Qeydiyyat / Регистрация**, задайте
  имя пользователя, пароль (мин. 8 символов, буква + цифра) и Telegram Chat ID.

Защита: после 5 неудачных попыток вход блокируется на 15 минут.

## 3. Главный экран (Dashboard)

Слева — панель управления, справа — рабочая область.

**Метрики сверху:** устройства, открытые порты, risk score, инциденты, статус
Telegram.

**Network Scan (сканирование сети):**
1. Введите цель (IP, диапазon CIDR, хост или `localhost`) в поле сверху.
2. Нажмите **Start Scan** / **Network Scan**.
3. В «Scan Console» появятся открытые порты, риски и рекомендации.

**Port Control:** переключатели портов — открыть/закрыть порт в firewall.
**Allow All / Block All** — массово. **Harden Risky** — закрыть рискованные порты.

**Guard (DDoS):** мониторинг всплесков трафика; ползунок задаёт
чувствительность. **Port Canary** — порты-ловушки: любое подключение к ним =
сигнал о сканировании/атаке.

**Telegram Alerts:** вставьте Chat ID → **Save & Test**. Дальше сканы и алерты
приходят в этот чат. Как получить Chat ID: напишите боту `/start`.

**AI Engine (NVIDIA):** вставьте API-ключ NVIDIA → **Save & Apply**. Это
включает AI-копилота и AI-вердикт в антифишинге. Без ключа работает офлайн-режим.

**AI-копилот** (внизу справа): задавайте вопросы на азербайджанском/русском/
английском: «445 portu niyə təhlükəlidir?», «закрой порт 3389», «объясни
последний скан».

## 4. Антифишинг

Вкладка **Anti-Phishing Analysis** сверху.
1. Вставьте URL.
2. **Quick Check** — быстрые офлайн-проверки URL; **Full Analyze** — плюс
   загрузка страницы, TLS-сертификат, контент, орфография и AI-вердикт.
3. Смотрите список сигналов, итоговый балл 0–100 и вердикт.
4. **Send to SOC Cases** — завести инцидент из результата.

## 5. SOC Operations Console

Кнопка **Open SOC Console** в левой панели. Это рабочее место аналитика.
Данные обновляются автоматически (обновляется только открытая вкладка).

- **Triage Queue** — поток событий безопасности. Фильтр по severity. Кнопка
  **→ Incident** превращает событие в инцидент.
- **Incidents** — карточки инцидентов: статус (Open→Investigating→Contained→
  Resolved), severity, ответственный, техника MITRE, заметки расследования.
  Кнопка **+ New Incident** — создать вручную.
- **Endpoints & Agents** — сервера/ПК с агентом (см. раздел 6), коллектор,
  syslog и firewall-интеграция.
- **Detection Rules** — правила детекции (см. раздел 8).
- **Threat Intel** — список индикаторов (IOC): добавить/удалить/проверить.
- **Log Search** — поиск по всем собранным логам.
- **Metrics** — KPI: открытые/критические/закрытые инциденты, объём событий,
  число эндпоинтов, IOC.

## 6. Подключение сервера (агент)

1. В **Endpoints & Agents** нажмите **Start Collector**.
2. Нажмите **Copy Install Command** — команда с адресом сервера и токеном.
3. На нужном сервере вставьте её в терминал:
   ```bash
   curl -fsSL http://<ip>:8787/agent | sudo python3 - --server http://<ip>:8787 --token <токен>
   ```
4. Через пару секунд сервер появится как **online**. Кнопка **Details**
   покажет: систему, IP, аптайм, ресурсы, процессы, **какой процесс какой порт
   слушает и куда подключается**, неудачные входы.

Для постоянной работы оформите агента как systemd-сервис (см.
[AGENTS_AND_ROADMAP.md](../AGENTS_AND_ROADMAP.md)).

## 7. Реагирование на эндпоинте

Для каждого агента в **Endpoints & Agents**:

- **Scan Ports** — внешний nmap-скан эндпоинта; подсвечивает порты, открытые
  снаружи, но не заявленные агентом (возможный скрытый/внедрённый сервис).
- **Isolate** — сетевая изоляция: агент рвёт весь трафик, кроме связи с
  AutoSOC (чтобы можно было снять изоляцию). Появляется бейдж 🔒 ISOLATED.
- **Release** — снять изоляцию.

Требуется агент, запущенный с правами root/администратора.

## 8. Правила детекции

Вкладка **Detection Rules**. По умолчанию ~35 правил (как в промышленных SIEM),
привязанных к MITRE ATT&CK. Они автоматически проверяют каждый лог и телеметрию.

- Переключатель включает/выключает правило.
- **+ Add Rule** — своё правило: имя, регулярное выражение, severity, MITRE,
  порог/окно, «открыть инцидент», «заблокировать IP».
- Кастомные правила можно удалять; встроенные — только отключать.

Сработавшее правило создаёт событие, а по настройке — инцидент и/или блокировку
IP. High/Critical дублируются в Telegram.

## 9. Сетевые firewall (FortiGate, Palo Alto, MikroTik, pfSense)

В **Endpoints & Agents → Network Firewall & Syslog**:

- **Start Syslog** — приёмник логов (UDP :5514). Направьте на него syslog
  устройства — логи попадут в Log Search, брутфорс поднимет событие.
- **Firewall block-list feed** (`/blocklist.txt`) — укажите этот URL в
  FortiGate Threat Feed / Palo Alto EDL / pfBlockerNG / MikroTik, и устройство
  само будет дропать заблокированные IP.
- **Firewall Integration** — прямой push блокировок в FortiGate по API.
- **Blocklist** — ручное добавление/снятие блокировок.

## 10. Журналы и аудит

- На дашборде **Audit Journal** — история сканов, событий и действий.
- Все действия операторов (вход, блокировки, изоляция, изменения правил)
  пишутся в аудит.
- Данные хранятся локально в защищённом каталоге пользователя (только владелец):
  `~/.local/share/autosoc` (Linux) / `%APPDATA%\AutoSOC` (Windows).

## Частые вопросы

- **Эндпоинт не появляется** — нажмите Refresh; убедитесь, что коллектор
  запущен и сервер доступен по сети.
- **«Isolation needs root»** — запустите агента через `sudo`.
- **Firewall-команды не срабатывают** — запустите приложение с
  админ-правами/`sudo`.
- **Нет AI-ответов** — добавьте ключ NVIDIA в левой панели.
